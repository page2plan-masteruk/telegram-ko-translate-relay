Telegram 번역 자동화 문제 해결 가이드

에러가 났을 때 증상별로 확인하고 바로 복구하는 문서입니다. 먼저 빠른 진단을 실행한 뒤, 에러 문구와 맞는 항목을 보세요.

목차 빠른 진단 .env 설정 문제 원본 Telegram 문제 번역방 Telegram 문제 DeepL 번역 문제 KakaoTalk 문제 이미지 문제 긴 텍스트 문제 과거 메시지/중복 문제 Python 실행 문제 보안 주의

빠른 진단

문제가 생기면 아래 명령어를 위에서부터 차례대로 실행하세요.

cd C:\path\to\telegram-kakao-translator
.\.venv\Scripts\python.exe validate_env.py
.\.venv\Scripts\python.exe test_telegram.py
.\.venv\Scripts\python.exe test_telegram_target.py
.\.venv\Scripts\python.exe test_deepl.py
.\.venv\Scripts\python.exe test_kakao.py
Telegram 원본이 문제 채널 못 찾음 FloodWait

먼저 list_telegram_chats.py로 채널 ID를 다시 확인합니다.

Telegram 번역방이 문제 Target 실패 권한 없음

test_telegram_target.py가 성공하는지 확인합니다.

번역이 문제 DeepL 실패

DEEPL_API_KEY와 DeepL 사용량 한도를 확인합니다.

KakaoTalk이 문제 401 토큰 만료

test_kakao.py로 토큰 갱신 여부를 확인합니다.

.env 설정 문제

설정 파일은 하나만 사용합니다.

C:\path\to\telegram-kakao-translator\.env

진단 명령어

.\.venv\Scripts\python.exe validate_env.py

성공 기준

마지막에 .env looks ready. Secret values were not printed.가 나오면 기본 설정은 정상입니다.

자주 빠지는 값

값 설명
TELEGRAM_CHANNEL 읽어올 영문 Telegram 채널 ID입니다.
TELEGRAM_TARGET_CHANNEL 한글 번역 메시지를 받을 Telegram 채널 ID입니다.
DEEPL_API_KEY 번역 API 키입니다.
KAKAO_ACCESS_TOKEN KakaoTalk 나에게 보내기용 토큰입니다.

원본 Telegram 문제

증상

Could not find TELEGRAM_CHANNEL
Cannot find any entity

해결 순서

  1. 접근 가능한 채널 목록을 확인합니다.
  2. 목록에서 원본 채널의 id를 찾습니다.
  3. .env의 TELEGRAM_CHANNEL에 그 ID를 넣습니다.
.\.venv\Scripts\python.exe list_telegram_chats.py
채널명은 바뀔 수 있으므로 @이름보다 숫자 ID를 쓰는 것이 안정적입니다.

번역방 Telegram 문제

대상 채널 예시

채널명 YOUR_KOREAN_TRANSLATION_CHANNEL
설정값 TELEGRAM_TARGET_CHANNEL=YOUR_TARGET_CHANNEL_ID

진단 명령어

.\.venv\Scripts\python.exe test_telegram_target.py

성공 기준

Telegram target test succeeded: YOUR_KOREAN_TRANSLATION_CHANNEL

새로 만들어야 할 때

.\.venv\Scripts\python.exe create_telegram_target.py
새 채널을 만들면 새 ID가 출력됩니다. 그 값을 .env의 TELEGRAM_TARGET_CHANNEL에 넣어야 합니다.

DeepL 번역 문제

증상

DEEPL_API_KEY is missing
DeepL test failed
HTTP 403 또는 HTTP 456

진단 명령어

.\.venv\Scripts\python.exe test_deepl.py

확인할 것

  1. .env의 DEEPL_API_KEY가 비어 있지 않은지 확인합니다.
  2. 무료 DeepL 키면 DEEPL_API_URL=https://api-free.deepl.com/v2/translate인지 확인합니다.
  3. 사용량 한도를 초과했는지 DeepL 계정 페이지에서 확인합니다.

KakaoTalk 문제

증상

Kakao test failed
HTTP 401
access token is expired

진단 명령어

.\.venv\Scripts\python.exe test_kakao.py

해결 방법

  1. 테스트 스크립트가 refresh token으로 새 access token 발급을 시도합니다.
  2. 새 KAKAO_ACCESS_TOKEN이 출력되면 .env에 붙여넣습니다.
  3. 새 KAKAO_REFRESH_TOKEN도 함께 출력되면 그것도 .env에 반영합니다.
카카오톡을 잠시 끄고 싶으면 .env에서 SEND_TO_KAKAO=false로 바꿉니다.

이미지 문제

Telegram 번역방 이미지 테스트

.\.venv\Scripts\python.exe test_telegram_image_target.py

성공 기준

Telegram image target test succeeded
YOUR_KOREAN_TRANSLATION_CHANNEL 채널에 이미지 파일과 번역 캡션이 올라갑니다.

KakaoTalk 이미지 카드 테스트

.\.venv\Scripts\python.exe test_image_pipeline.py

저장 위치

원본 이미지 downloaded_images
Kakao 카드 미리보기 kakao_previews
KakaoTalk은 로컬 파일을 직접 첨부하는 방식이 아니라, 이미지를 카카오 서버에 업로드한 뒤 이미지 카드로 보냅니다.

긴 텍스트 문제

진단 명령어

.\.venv\Scripts\python.exe test_long_text.py

성공 기준

Final marker preserved: True
Long text test sent to KakaoTalk.

관련 설정

설정 기본값 설명
KAKAO_TEXT_LIMIT 900 KakaoTalk 메시지를 나눌 기준입니다.
DEEPL_CHUNK_LIMIT 4500 DeepL 번역 요청을 나눌 기준입니다.
TELEGRAM_TEXT_LIMIT 3500 Telegram 번역방 메시지를 나눌 기준입니다. 설정이 없어도 기본값으로 작동합니다.

과거 메시지/중복 문제

과거 메시지가 한꺼번에 보내질까 걱정될 때

현재 기본값은 과거 메시지를 보내지 않고 최신 위치부터 시작합니다.

SEND_EXISTING_ON_FIRST_RUN=false

같은 메시지가 다시 보내지는 경우

state.json이 마지막 처리 메시지 번호를 기억합니다.

C:\path\to\telegram-kakao-translator\state.json
state.json을 함부로 지우면 과거 메시지가 다시 처리될 수 있습니다. 테스트 목적이 아니라면 건드리지 마세요.

Python 실행 문제

증상

python is not recognized
ModuleNotFoundError

해결 방법

이 프로젝트는 일반 python 대신 아래 경로를 사용하면 됩니다.

.\.venv\Scripts\python.exe validate_env.py

패키지 재설치

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

보안 주의

절대 공유하면 안 되는 파일
.env
telegram_session.session

이 파일들은 Telegram, Kakao, DeepL 접근 권한과 관련되어 있습니다. 다른 사람에게 보내거나 인터넷에 올리면 안 됩니다.
