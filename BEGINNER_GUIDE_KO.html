Telegram 영어 메시지 한국어 번역 자동화 초보자 가이드

영문 Telegram 채널의 새 메시지를 한국어로 번역해서 별도 Telegram 번역 채널과 KakaoTalk 나에게 보내기로 전달하는 방법입니다.

따라하기 순서 1. 전체 흐름 2. 준비 상태 3. 폴더 열기 4. 설정 확인 5. 테스트 6. 실제 실행 7. 멈추기 8. 주요 파일 9. 문제 해결

1. 전체 흐름

이 자동화는 Telegram 계정으로 원본 영어 채널을 읽고, DeepL로 한국어 번역을 만든 뒤, 두 곳으로 보내줍니다.

1
영문 Telegram 채널 읽기
원본 채널 ID 예시: YOUR_SOURCE_CHANNEL_ID
2
영어 메시지 한국어 번역
긴 글은 자동으로 나누어 번역하고, 다시 순서대로 보냅니다.
3
Telegram 한글 번역 채널로 전송
대상 채널 예시: YOUR_KOREAN_TRANSLATION_CHANNEL
4
KakaoTalk 나에게 보내기로 알림
카카오톡은 빠른 알림용, Telegram 번역 채널은 보관용으로 사용합니다.

2. 준비 상태

  • 확인Telegram 원본 채널 연결
  • 확인Telegram 한글 번역 채널 생성: YOUR_KOREAN_TRANSLATION_CHANNEL
  • 확인DeepL 번역 테스트
  • 확인KakaoTalk 전송 테스트
  • 확인이미지 파일 Telegram 전송 테스트
  • 확인긴 텍스트 분할 전송 테스트
실행 설정은 .env 파일 하나만 사용합니다. GitHub에는 실제 .env 파일을 올리지 말고, 본인 PC에서만 관리하세요.

3. 프로젝트 폴더 열기

PowerShell을 열고 아래 명령어를 입력합니다.

cd C:\path\to\telegram-kakao-translator

폴더 위치는 아래와 같습니다.

C:\path\to\telegram-kakao-translator

4. 설정 확인

설정 파일은 아래 파일입니다.

C:\path\to\telegram-kakao-translator\.env

중요 설정값

설정 의미 현재 상태
SEND_TO_KAKAO=true KakaoTalk 나에게 보내기를 켭니다. 사용 중
SEND_TO_TELEGRAM=true Telegram 한글 번역 채널 전송을 켭니다. 사용 중
TELEGRAM_TARGET_CHANNEL=YOUR_TARGET_CHANNEL_ID 한글 번역 메시지를 받을 Telegram 채널입니다. 직접 입력

설정이 빠졌는지 확인하려면 아래 명령어를 실행합니다.

.\.venv\Scripts\python.exe validate_env.py
성공 문구: .env looks ready. Secret values were not printed.

5. 테스트하기

처음 실행 전에는 아래 순서대로 테스트하면 어디에서 문제가 생겼는지 쉽게 알 수 있습니다.

1단계: Telegram 원본 채널 읽기

.\.venv\Scripts\python.exe test_telegram.py
성공하면 최근 원본 Telegram 메시지 몇 개가 표시됩니다.

2단계: Telegram 한글 번역 채널 연결

.\.venv\Scripts\python.exe test_telegram_target.py
성공 문구: Telegram target test succeeded

3단계: DeepL 번역

.\.venv\Scripts\python.exe test_deepl.py
성공 문구: DeepL test succeeded.

4단계: KakaoTalk 보내기

.\.venv\Scripts\python.exe test_kakao.py
성공 문구: Kakao test succeeded. Check your KakaoTalk.

5단계: Telegram과 KakaoTalk 동시 전송

.\.venv\Scripts\python.exe test_dual_pipeline.py
성공 문구: Dual pipeline test succeeded

6단계: Telegram 이미지 파일 전송

.\.venv\Scripts\python.exe test_telegram_image_target.py
성공 문구: Telegram image target test succeeded

7단계: 긴 텍스트 전송

.\.venv\Scripts\python.exe test_long_text.py
성공하면 KakaoTalk에 여러 개로 나뉜 긴 테스트 메시지가 도착합니다.

6. 실제 실행하기

모든 테스트가 성공했다면 아래 명령어로 자동화를 시작합니다.

.\.venv\Scripts\python.exe main.py

실행 중에는 새 메시지를 계속 확인합니다. 원본 Telegram 채널에 새 글이 올라오면 자동으로 번역해서 보냅니다.

한 번만 확인하고 끝내기

계속 실행하지 않고 한 사이클만 확인하려면 아래 명령어를 사용합니다.

.\.venv\Scripts\python.exe main.py --once

7. 멈추기

PowerShell 창에서 자동화가 실행 중일 때 멈추려면 키보드에서 아래를 누릅니다.

Ctrl + C

8. 주요 파일

파일 용도
.env API 키, 채널 ID, 전송 옵션이 들어 있는 실제 설정 파일입니다.
main.py 실제 자동화 실행 파일입니다.
downloaded_images Telegram에서 받은 이미지가 저장되는 폴더입니다.
kakao_previews KakaoTalk 이미지 카드용 미리보기 이미지가 저장되는 폴더입니다.
state.json 마지막으로 처리한 Telegram 메시지 번호를 기억합니다.
주의: .env와 telegram_session.session 파일은 절대 다른 사람에게 보내면 안 됩니다. 계정 접근 권한이 포함될 수 있습니다.

9. 문제 해결

Telegram 채널을 못 찾는 경우

접근 가능한 Telegram 채널 목록을 확인합니다.

.\.venv\Scripts\python.exe list_telegram_chats.py

목록에 보이는 id 값을 .env의 채널 값으로 쓰면 가장 안정적입니다.

KakaoTalk 메시지가 안 오는 경우

.\.venv\Scripts\python.exe test_kakao.py

토큰이 만료되면 스크립트가 갱신을 시도합니다. 새 토큰이 출력되면 .env에 반영합니다.

DeepL 번역이 안 되는 경우

.\.venv\Scripts\python.exe test_deepl.py

API 키 또는 DeepL 사용량 한도를 확인합니다.

이미지가 안 가는 경우

.\.venv\Scripts\python.exe test_telegram_image_target.py

성공하면 YOUR_KOREAN_TRANSLATION_CHANNEL 채널에 이미지 파일과 번역 캡션이 올라갑니다.

과거 메시지가 한꺼번에 보내질까 걱정되는 경우

현재 기본값은 기존 과거 메시지를 보내지 않도록 되어 있습니다.

SEND_EXISTING_ON_FIRST_RUN=false
문제가 반복되면 자동화를 멈춘 뒤 validate_env.py부터 다시 실행하세요. 대부분의 문제는 설정값, 채널 ID, 토큰 만료 중 하나입니다.
